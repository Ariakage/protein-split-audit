# Support policy

ProteinSplitAudit is maintained as research software. The latest tagged release and the current
development branch receive best-effort support; no response-time or compatibility service level is
promised.

Use GitHub Issues for:

- reproducible installation or runtime failures;
- documentation errors;
- narrowly scoped feature proposals; and
- reports from the independent reproduction protocol.

Include the package version, operating system, architecture, Python version, sanitized command,
expected behavior, observed behavior, and a minimal synthetic reproduction. Do not attach protein
records, accessions, private paths, credentials, model weights, formal ledgers, or unpublished
record-level results.

Public support cannot authorize access to the consumed Test sessions, rewrite an immutable release
artifact, or approve a scientific protocol. Those actions remain governed by the frozen protocol
and maintainer authority.

For a suspected security issue, follow `SECURITY.md` instead of opening a public issue.

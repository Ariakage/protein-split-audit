# ProteinSplitAudit v0.4.0

ProteinSplitAudit v0.4.0 adds two frozen ESM-2 representation baselines to the unchanged
`pilot-v1` cohort and four splits released in v0.2.0. The release is Validation-only, and the real
Test split remains closed.

## What is included

- Pinned local snapshots of `facebook/esm2_t12_35M_UR50D` and
  `facebook/esm2_t30_150M_UR50D`, each fixed to a full Hugging Face commit revision.
- Last-layer residue representations with special tokens excluded from mean pooling.
- Dense float32 embeddings generated on CPU without truncation or fine-tuning.
- A Train-only StandardScaler and the fixed v0.3 logistic-regression protocol.
- Eight Validation cells covering two models and Random, Cluster70, Cluster50, and Cluster30.
- Offline snapshot verification, immutable embedding caches, run provenance, deterministic replay,
  and six reviewed aggregate files.

The two formal matrices were generated independently from empty embedding caches on the same
Darwin arm64 CPU environment. Both completed all eight cells. The replay compared 97
deterministic artifacts and found every file byte-identical. It reported
`replay_difference: 0` and `release_eligible: true`. A direct comparison also found all 24
embedding cache files byte-identical.

## Published aggregate files

The release directory contains the ESM summary and per-class tables, a verified
classical-versus-ESM table, the embedding schema, model snapshot hashes, the environment summary,
the protocol attestation, and a short README. It contains no protein sequences, accessions,
per-record predictions, embeddings, model weights, fitted estimators, private paths, or secrets.

`real_test_access_authorized: false`

These results check the implementation and replay contract on a small E. coli K-12 pilot. They do
not establish final benchmark performance. The project has not audited whether any pilot sequence
appeared in ESM-2 pretraining data, so sequence-level split controls do not establish independence
from the pretraining corpus.

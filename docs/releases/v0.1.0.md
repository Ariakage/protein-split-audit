# ProteinSplitAudit v0.1.0

## Overview

ProteinSplitAudit v0.1.0 is the first public release of the reproducible candidate-dataset
pipeline. The annotated `v0.1.0` tag and GitHub Release were published on 2026-07-14.

This is a software release. It provides tools for downloading, validating, deduplicating, and
profiling a candidate protein enzyme dataset, but it does not publish a frozen dataset or report
scientific results.

The pre-release readiness review, including criteria that were incomplete when the version was
published, is preserved in `docs/audits/v0.1.0-pre-release-readiness.md`.

## Included

- A Python 3.12 project installed from a checked-in uv lockfile.
- `psaudit --version` and the local, non-networked `psaudit doctor` diagnostic.
- `psaudit data download`, `psaudit data build`, and `psaudit data profile`.
- A validated E. coli K-12 pilot configuration under `configs/dataset/pilot.yaml`.
- Paginated UniProtKB/Swiss-Prot TSV downloads that follow `Link` relations and use bounded retry
  behavior for transient failures.
- One normalized TSV stream with deterministic gzip compression and download provenance.
- Validation for one complete four-level EC annotation, EC-level-2 mapping, the standard
  20-amino-acid alphabet, and sequence lengths from 50 to 1000 residues.
- Exact-sequence duplicate canonicalization and whole-group rejection for conflicting
  EC-level-2 labels.
- Deterministically ordered local Parquet and FASTA candidate files.
- Aggregate-only candidate profiles with class, sequence-length, organism, filtering, and
  deduplication summaries.
- Offline pytest coverage with mocked HTTP transport and an application-level socket guard.
- Ruff, Ruff formatting, strict MyPy, pytest, a GitHub Actions quality workflow, and uv package
  builds.

## Not included

- Final EC class selection or a frozen benchmark dataset.
- MMseqs2 or any other sequence-similarity clustering.
- Train, validation, or test splits.
- AAC, k-mer, ESM-2, or other feature extraction.
- Model training or evaluation.
- A dashboard.
- Scientific conclusions, leakage estimates, performance metrics, or benchmark claims.

## Known limitations

- The planned `psaudit config validate` and `psaudit data run` commands are not implemented.
- Source query validation checks that the query is nonblank, but it does not enforce every
  reviewed-bacterial query term from the plan.
- Retry behavior is bounded and tested, but failed retry attempts are not written to a local
  attempt audit.
- Invalid EC and sequence rows contribute to aggregate rejection counts; there is no per-record
  rejection table or complete terminal accounting artifact.
- EC parsing returns one accepted value or one rejection reason. It does not preserve original
  tokens and token-level outcomes, strip an optional `EC=` prefix, or enforce positive nonzero EC
  components as specified in the plan.
- Sequence normalization strips leading and trailing whitespace and uppercases the result. It
  rejects internal ASCII whitespace instead of removing it.
- Download and build manifests combine deterministic content hashes with run timestamps rather
  than separating content manifests from timestamped run provenance.
- No GitHub Actions run is recorded for the tagged release commit. The verification results in the
  post-release correction audit are local results.

## Installation

From a repository checkout:

```bash
uv sync --locked
uv run psaudit --version
uv run psaudit doctor
```

The GitHub Release contains these package files:

- `protein_split_audit-0.1.0-py3-none-any.whl`
- `protein_split_audit-0.1.0.tar.gz`

To run the wheel without installing the project checkout:

```bash
uv run --isolated --no-project \
  --with ./protein_split_audit-0.1.0-py3-none-any.whl \
  psaudit --version
```

## Verification

```bash
uv sync --locked
uv run psaudit --version
uv run psaudit doctor
uv run ruff check .
uv run ruff format --check .
uv run mypy src
uv run pytest
uv build
```

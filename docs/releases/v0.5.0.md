# ProteinSplitAudit v0.5.0

ProteinSplitAudit v0.5.0 opens the frozen Test partition for the first controlled Test pilot. It
uses the unchanged 442-protein, five-class *E. coli* K-12 cohort, the four v0.2 splits, five
classical methods from v0.3, and two frozen ESM-2 methods from v0.4.

## What is included

- A fail-closed Test authorization capability bound to Git state, inputs, model snapshots,
  configuration, runtime, and an owner-authored approval.
- A fixed 28-cell matrix covering seven methods and Random, Cluster70, Cluster50, and Cluster30.
- Train-only fitting, no Validation use, unlabeled Test prediction, and delayed Test-label access.
- Cluster30-component bootstrap intervals with 2,000 draws, paired within-split comparisons, and
  independently resampled Random-minus-cluster gaps.
- Twelve reviewed aggregate files with complete input and replay provenance.

## Reading the pilot results

The released tables report all 28 Test cells. Each cell has 66 Test records and complete
prediction coverage. The 32 prespecified ESM-versus-AAC or ESM-versus-3-mer directed differences
were positive, with paired component-bootstrap intervals above zero. The eight ESM-2
150M-minus-35M intervals included zero. All 21 Random-minus-cluster Macro-F1 intervals also
included zero.

These intervals are descriptive. They are not p-values or significance tests. The results come
from one small, class-imbalanced organism-specific cohort, one frozen seed, and one fixed method
set. They do not establish a universal model ranking, a representative bacterial-enzyme
benchmark, or independence from ESM-2 pretraining data.

## Published files and privacy boundary

`results/released/v0.5.0/` contains the aggregate summary and per-class tables, complete aggregate
confusion counts, confidence intervals, generalization gaps, method comparisons, Nearest Homolog
summary, environment summary, input hashes, replay report, attestation, and a short README.

The release does not include protein sequences, accessions, record-level predictions,
confidence values, correctness flags, nearest-neighbor pairs, embeddings, fitted models, caches,
logs, access ledgers, incident files, or private local paths.

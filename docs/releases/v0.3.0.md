# ProteinSplitAudit v0.3.0

ProteinSplitAudit v0.3.0 adds a reproducible classical feature, baseline, and Validation evaluation
pipeline on top of the frozen v0.2.0 `pilot-v1` cohort and split manifests.

## Release contents

- deterministic Length, 20-dimensional amino-acid composition, and fixed 8,000-dimensional 3-mer
  feature representations;
- Majority, three fixed logistic-regression baselines, and a training-only MMseqs2 Nearest Homolog
  baseline;
- one fixed seed and a 5-baseline × 4-split Validation matrix;
- train-only preprocessing and fitting, deterministic class order, and explicit Nearest Homolog
  no-hit handling;
- run provenance, resource reporting, completion markers, and deterministic replay comparison;
- four reviewed, aggregate Validation files and a machine-readable protocol attestation.

The formal matrix was executed twice from clean Generation Commit A. All 169 deterministic
artifacts compared by the replay check were byte-identical, with zero mismatches. Run-specific
timestamps, logs, environment files, and resource measurements were excluded from the byte-level
comparison by design.

## Publication boundary

The release publishes `validation_summary.csv`, `validation_per_class.csv`,
`feature_schema.json`, `environment_summary.json`, the protocol attestation, and a short artifact
README. It does not publish sequences, accessions, feature caches, fitted models, predictions,
neighbor rows, confusion matrices, or complete run directories.

The real Test split was not accessed. These are Validation-only Pilot results used to verify the
pipeline and its reproducibility; they are not final benchmark results or a scientific conclusion
about the relative merits of random and cluster-aware splits.

# ProteinSplitAudit v0.7.0

ProteinSplitAudit v0.7.0 adds public reproduction and manuscript infrastructure for a planned
methods/software paper. It does not train or run a model, repeat Test inference, change a split,
open another Test session, or modify any frozen v0.5.0 or v0.6.0 artifact. The released pilot
remains the 442-protein, five-class *E. coli* K-12 subject, not a general benchmark.

## What is included

- A deterministic, fully offline synthetic end-to-end demonstration (`psaudit demo run`) covering
  strict similarity components, Random and Cluster30 splitting, Train-only AAC extraction, fixed
  logistic regression, aggregate evaluation, and no-overwrite publication. Repeated runs produce
  byte-identical artifacts; its metrics verify software behavior and are not scientific results.
- A bilingual (English and Chinese) Typst manuscript draft in `docs/paper/`, with build
  instructions and a number cross-check script (`scripts/verify_manuscript_numbers.py`) whose
  results are recorded in `docs/attestations/manuscript-number-verification.json`.
- A submission readiness checklist (`paper/readiness.yaml`) with a JOSS draft skeleton
  (`paper/paper.md`) kept consistent with repository metadata.
- Public governance, security, support, issue and pull-request templates, venue assessment,
  independent-reproduction protocol, and tutorial documentation.
- A container-based clean-checkout verification script (`scripts/container_reproduction.sh`) and
  its attempt record (`docs/attestations/container-clean-checkout-attempt.md`). The record was
  produced by the maintainer's AI agent and explicitly does not claim independent reproduction.

## Metadata changes

- `CITATION.cff` now describes v0.7.0, the latest stable release. Author metadata is unified on
  Aria Chen, with the legal name retained as an alias in `CITATION.cff` only.
- `.zenodo.json` carries archive metadata without a DOI. No DOI is declared until a deposit
  exists.
- `paper/readiness.yaml` keeps `submission_status: blocked`. Independent reproduction by someone
  other than the main implementer and a Zenodo archive DOI remain the two open submission
  blockers.

## Frozen execution lineage

All scientific numbers in the repository trace to the v0.5.0 frozen Test evaluation
(Generation Commit A5 `5d5a7e817acb2b271b0353536ed4a270e104d18c`, Attestation Commit B2
`73febd1be2a18d3c9b54f7aacf5cd90a208fbd52`, identity revision r1) and the v0.6.0 post-Test
analysis over those frozen predictions. v0.7.0 adds no new session, prediction, or aggregate
result to that lineage.

## Release scope

v0.7.0 is a reproducibility and manuscript release. It publishes no new sequence, prediction,
model, or Test-derived artifact. Real Test access remains restricted to the two consumed formal
sessions, and the submission blockers listed above must be satisfied before any journal
submission.

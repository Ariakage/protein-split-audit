# ProteinSplitAudit v0.1.1

## Overview

v0.1.1 is a corrective tag for the public documentation and release metadata associated with
ProteinSplitAudit v0.1.0. It does not change downloader, dataset-building, profiling, or command
behavior, and it does not publish a new dataset.

## Corrected

- The README and changelog now state that v0.1.0 was published as the project's first public
  software release.
- `docs/releases/v0.1.0.md` now contains release notes instead of the pre-release readiness
  report.
- The original readiness report is preserved under `docs/audits/` with its historical context.
- Package, lockfile, and citation metadata now consistently report version 0.1.1.
- The existing v0.1.0 GitHub Release notes are updated from the corrected release-notes file, and
  a `SHA256SUMS` file generated from the already published v0.1.0 assets is attached separately.

## Unchanged scope

The pipeline capabilities and known limitations remain those documented in
`docs/releases/v0.1.0.md`. In particular, this correction does not add final EC class selection,
sequence-similarity clustering, data splits, feature extraction, model training, benchmark
results, or a frozen dataset.

The annotated v0.1.0 tag and its wheel and source-distribution assets are not moved or replaced.
No v0.1.1 GitHub Release is part of this corrective operation.

## Verification

The corrective commit is checked with the locked dependency environment:

```bash
uv lock --check
uv sync --locked
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked mypy src
uv run --locked pytest
uv build
```

The v0.1.1 wheel is also exercised with uv's isolated, no-project smoke-test pattern using
`psaudit --version` and `psaudit doctor`.

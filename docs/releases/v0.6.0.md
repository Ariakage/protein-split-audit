# ProteinSplitAudit v0.6.0

ProteinSplitAudit v0.6.0 adds a prespecified post-Test analysis and robustness audit over the
already frozen v0.5.0 predictions. It does not train or run a model, repeat Test inference, change
a split, or create another Test session. The subject remains the 442-protein, five-class *E. coli*
K-12 pilot, not a general benchmark.

## What is included

The release contains exactly 19 reviewed public files:

- ten sequence-free aggregate CSV tables covering split performance, fixed identity and length
  bins, class-level errors, component size and influence, Nearest Homolog behavior, model
  comparisons, prediction agreement, and robustness checks;
- an aggregate analysis manifest and an exact-replay report;
- six deterministic PDF figures generated only from the reviewed CSV tables; and
- a short aggregate README.

All confidence intervals use the frozen Cluster30 discovery component as the bootstrap unit. The
tables keep the fixed method, split, class, bin, comparison, and reporting order. Privacy rules
suppress small groups and omit unsupported estimates instead of plotting them as zero.

## Reading the results

The outputs are descriptive summaries of one small, class-imbalanced, organism-specific pilot.
Bootstrap intervals describe uncertainty under the frozen component-resampling protocol; they are
not p-values or a claim of statistical significance. Empty areas in a figure mean the relevant
group was suppressed or lacked prespecified support. They do not mean an estimate of zero.

The release does not establish a universal model ranking, a representative bacterial-enzyme
benchmark, biological independence, or independence from ESM-2 pretraining data. Exploratory
patterns remain outside the confirmatory release bundle.

## Access and privacy boundary

No additional Test access, Test inference, model execution, or formal analysis session is
authorized. Release Commit C copies the reviewed aggregate bytes into
`results/released/v0.6.0/`; it does not regenerate them.

The release excludes sequences, accessions, row-level predictions, correctness flags, nearest
neighbors, features, embeddings, fitted models, caches, run provenance, access ledgers, incident
files, private paths, and secrets. The original incident, both r1 ledgers, formal outputs, replay,
and blocked visual-review evidence remain local and unchanged.

The public bundle can be checked without opening Test inputs:

```bash
shasum -a 256 results/released/v0.6.0/* \
  results/released/v0.6.0/figures/*
uv run --locked pytest tests/test_v060_release_artifacts.py \
  tests/test_v060_release_privacy.py -v
```

Generation Commit A of v0.5.0. The comparison parses both TOML documents and compares normalized
objects; it does not rely on line-oriented output alone.

## Conclusion

The two lockfiles resolve the same third-party environment. Their only byte-level and semantic
difference is the approved root package version change from 0.4.0 to 0.5.0. The full-file SHA-256
of this report is computed after the file is finalized and belongs in the Generation A approval
bundle; embedding a file's own digest here would be self-referential.

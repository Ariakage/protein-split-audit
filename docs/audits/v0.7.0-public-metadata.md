# v0.7.0 public repository metadata correction

On 2026-08-29, the GitHub About description called ProteinSplitAudit a “reproducible benchmark.”
That wording contradicted the released data card, limitations, and methods-paper claim boundary:
the current evidence is a bounded single-organism pilot, not a general benchmark.

The repository description was changed to:

> An auditable toolkit for similarity-aware protein classification datasets, splits, leakage
> checks, and reproducible evaluation.

The change affected GitHub repository metadata only. It did not create a commit, push code, move a
tag, alter a release, access Test, or regenerate an artifact.

GitHub still reported no detected repository license at the time of this check because the public
default branch contains the canonical Apache-2.0 text only under `LICENSES/`. The v0.7 development
work adds a byte-identical root `LICENSE` and explicitly includes it in wheel and source
distributions. License detection must be checked again after that reviewed change reaches the
default branch; it must not be claimed complete before then.

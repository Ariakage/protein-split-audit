## Conclusion

The two lockfiles resolve the same third-party environment. Their only byte-level and semantic
difference is the root package version change from 0.5.0 to 0.6.0. This report's own SHA-256 is
computed after finalization and belongs in the later approval bundle; embedding it here would be
self-referential.
